# I love you Basbosty — 5 Months

مشروع تفاعلي متوافق مع الموبايل والتابلت والكمبيوتر لمناسبة مرور 5 شهور من 21/6/2026 إلى 21/11/2026.

## إضافة الأغنية
1. ضع ملف الأغنية بصيغة MP3 داخل مجلد `public/` وسمّه `song.mp3` (المسار: `public/song.mp3`).
2. عند الضغط على زر **دوسي هنا يعمري** ستعمل الأغنية تلقائياً، ويظهر زر أعلى الشاشة للتحكم في التشغيل أو الكتم.
